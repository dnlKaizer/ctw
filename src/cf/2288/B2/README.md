# 2288B2 - Yukari Yakumo and the Boundary Stones (Hard Version)

- **Link:** https://codeforces.com/contest/2288/problem/B2
- **Tópicos:** Constructive Algorithms, Greedy, Interactive
- **Ideia central:** Dado um inteiro positivo $N$ que representa a quantidade de pedras, determinar, a partir de uma query, a soma dos poderes dessas $N$ pedras. A query será composta por uma string $s$, com tamanho máximo igual a $10N$, no qual Yukari Yakumo vai escolher o índice $k$ em que o número de pedras ao final das primeiras $k$ operações é máximo. O valor $k$ será imprimido logo após a query, pois é um problema interativo. (1) Se $s_i
$ = +, pode-se aumentar o poder de uma pedra de $1$ para $2$ ou, se já existir alguma pedra de poder $2$, adicionar uma nova pedra de poder $2$. (2) Se $s_i$ = -, pode-se reduzir o poder de uma pedra de $2$ para $1$, se existir, ou remover uma pedra de poder $1$
- **Insight:** A ideia consiste em uma query que é capaz de identificar quantas pedras de poder $2$ existem inicialmente. A string $s$ será formada por $N$ sequências da combinação "+--". Analisando a operação "+--", percebe-se que, caso seja adicionada uma pedra de poder $2$, a operação não muda a soma total dos poderes das pedras, mas como vale a pena manter mais pedras, ao invés de adicionar uma nova pedra de poder $2$ e removê-la, o ideal é adicionar uma pedra de poder $2$, e reduzir o poder de duas pedras de poder $2$ para $1$, o que aumente o número de pedras totais mas reduz o nível de uma das pedras originais. Basicamente, há duas opções para cada situação: (1) o conjunto de pedras atual não possui nenhuma pedra de poder $2$, então $k$ para no último +, ou (2) existe pelo menos uma pedra de poder $2$ no conjunto atual, então vale a pena adicionar uma pedra de poder $2$ e avançar mais uma iteração. Se o conjunto de pedras atual tiver somente pedras de poder $1$, ele vai parar em $k = 0$, pois não dá para adicionar mais nenhuma nova pedra. Caso contrário, se tiver $y$ pedras de poder $2$, $k = 3y - 2$, pois sempre vale a pena adicionar uma nova pedra de poder $2$
- **Complexidade:** Tempo $O(N)$, Espaço $O(1)$
- **Pontos de atenção:** Nenhum
