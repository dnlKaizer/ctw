# 2290A - Three Piles

- **Link:** https://codeforces.com/contest/2290/problem/A
- **Tópicos:** Implementation, Math
- **Ideia central:** Definir se é possível formar 3 pilhas iguais a partir de uma operação obrigatória de remover 1 e adicionar 1 a outra pilha
- **Insight:** Ordenar um vetor de 3 elementos e verificar se a diferença entre elementos adjacentes é igual a 1
- **Complexidade:** Tempo $O(1)$, Espaço $O(1)$
- **Pontos de atenção:** Nenhum
