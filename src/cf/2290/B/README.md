# 2290B - Stubborn Pen

- **Link:** https://codeforces.com/contest/2290/problem/B
- **Tópicos:** Implementation, Strings
- **Ideia central:** Verificar quantas trocas manuais seriam necessárias para que a string seja igual à desejada.
- **Insight:** Manter uma variável de estado atual e verificar se a letra atual é igual à letra desejada. Se não for, incrementar o contador de trocas e atualizar o estado atual.
- **Complexidade:** Tempo $O(N)$, Espaço $O(1)$
- **Pontos de atenção:** Nenhum
