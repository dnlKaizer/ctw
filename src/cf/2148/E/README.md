# 2148E - Split

- **Link:** https://codeforces.com/contest/2148/problem/E
- **Tópicos:** Data Structures, Two Pointers
- **Ideia central:** Dado um array, contar o número de subarrays perfeitos. Dado $K$ multisets, um subarray é perfeito se, considerando duas operações, é possível que todos os multisets se tornem iguais. Considerando $a_i$ ($1 \leq i \leq n$) um elemento do array $a$ e o subarray sendo formado por $a[l,r]$, as operações são: $(1)$ Se $l \leq i \leq r$, coloca $a_i$ no multiset $1$. $(2)$ Se não, coloca $a_i$ em qualquer multiset, inclusive o $1$.
- **Insight:** Se a quantidade de qualquer elemento $a_i$ no array não for divisível por $K$, então não é possível formar um subarray perfeito, caso contrário, é possível. Existe uma única solução para organizar os elementos nos multisets, pois todos são iguais. Se um número $a_i$ aparece $K \times C$ no array original, então o subarray perfeito deve conter no máximo $C$ elementos $a_i$. Portanto, para cada elemento $a_i$, podemos manter um contador de quantos elementos $a_i$ já foram adicionados ao subarray atual. Se o contador for maior que $C$, então o subarray não é perfeito. Caso contrário, ele é perfeito. Para contar o número de subarrays perfeitos, podemos usar a técnica de two pointers, mantendo um ponteiro $l$ e outro $r$, e expandindo $r$ enquanto o subarray formado por $a[l,r]$ for perfeito. Quando não for mais perfeito, incrementamos $l$ até que volte a ser perfeito. A resposta é fazer uma soma $r-l$ a um contador $ans$ a cada vez que $r$ é incrementado.  
- **Complexidade:** Tempo $O(N)$, Espaço $O(N)$
- **Pontos de atenção:** A resposta é quadrática no maior caso, então $(10^5)^2 = 10^{10}$, o que não cabe em $int$ de $32$ bits. Portanto, é necessário usar $long long$ para armazenar a resposta.
