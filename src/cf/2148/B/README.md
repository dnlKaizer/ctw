# 2148B - Lasers

- **Link:** https://codeforces.com/contest/2148/problem/B
- **Tópicos:** Geometry
- **Ideia central:** Encontrar o menor número de vezes que um caminho de &(0,0)& até &(N,N)& cruza linhas de laser horizontais e verticais.
- **Insight:** Como todos os lasers estão entre &(0,0)& e &(N,N)&, qualquer caminho de &(0,0)& até &(N,N)& deve cruzar no mínimo todos os lasers. Portanto, o problema se reduz a contar o número de lasers horizontais e verticais.
- **Complexidade:** Tempo $O(1)$, Espaço $O(1)$
- **Pontos de atenção:** Nenhum
