# 2148A - Sublime Sequence

- **Link:** https://codeforces.com/contest/2148/problem/A
- **Tópicos:** Brute Force, Math
- **Ideia central:** Encontrar a soma da sequência de inteiros $x, -x, x, -x, ...$ até $N$ termos.
- **Insight:** Se $N$ é par, a soma será $0$, pois os termos se cancelam. Se $N$ é ímpar, a soma será $x$, pois o último termo não é cancelado.
- **Complexidade:** Tempo $O(1)$, Espaço $O(1)$
- **Pontos de atenção:** Nenhum
