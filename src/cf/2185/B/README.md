# 2185B - Prefix Max

- **Link:** https://codeforces.com/contest/2185/problem/B
- **Tópicos:** Greedy
- **Ideia central:** Encontrar o a maior soma de prefixos máximos de uma array, podendo fazer uma troca de elementos
- **Insight:** Como o primeiro elemento do array pertence a todos os prefixos, basta trocar o maior elemento do array com o primeiro elemento para maximizar a soma dos prefixos
- **Complexidade:** Tempo $O(n)$, Espaço $O(1)$
- **Pontos de atenção:** Nenhum
