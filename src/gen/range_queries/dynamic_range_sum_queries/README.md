# Dynamic Range Sum Queries

- **Link:** https://cses.fi/problemset/task/1648/
- **Tópicos:** Range Queries, Data Structures
- **Ideia central:** Determinar a soma de elementos em um intervalo com atualizações de elementos individuais
- **Insight:** Implementar uma Fenwick Tree (BIT) para manter as somas parciais e permitir atualizações eficientes
- **Complexidade:** Tempo $O(N\log{N})$, Espaço $O(N)$
- **Pontos de atenção:** Nenhum
